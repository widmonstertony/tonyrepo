Tony Native Network Speed

0.1.1 已验证于 iPad14,6 / iPadOS 16.1。完整保留当前已工作的 arm64/arm64e 二进制；正式包只整理名称与说明。

下载/上传速度嵌入右侧原生状态栏，位于 Wi-Fi/电池前，不创建悬浮窗。K/M 为 KiB/s 与 MiB/s，低于 1 KiB/s 显示 0K 属正常现象。只注入 SpringBoard，不注入 CoC 或其他游戏。

默认开启，在设置的「右上角实时网速 / Network speed」开关关闭。安装后需重启一次 SpringBoard；若此设备正在运行虚拟 Mac，请先保存并关闭虚拟 Mac。包内没有自动重启脚本。

English

Verified native right-side status-bar download/upload display on iPad14,6 / iPadOS16.1. No draggable HUD or extra window. Default enabled with a Settings switch. Restart SpringBoard once after installation; save and close a VM hosted on the same iPad first. Other device/OS profiles are not implied by the dual-architecture binary.
