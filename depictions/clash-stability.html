Clash Stability 1.0.58

修复当前已验证组合：CoC 18.647.2、iPad14,6、iPadOS 16.1 (20B82)、Dopamine 3.0.11。 这个新版不宣称支持其他系统或 iOS 17。保留旧版 1.0.41 APT 条目供原兼容组合使用。

安装与验收

退出 CoC，更新插件，再打开游戏。Choicy 自定义允许列表需允许 ClashTraceDiagnostic。DEB 没有重启或 respring 安装脚本；不需要退出越狱、 清除游戏数据或重启设备。卸载后重新打开游戏即可移除注入。

已实际进入村庄，结束游戏后重新进入村庄，返回虚拟 Mac 后同一进程观察存活至三分十九秒。 此为当前组合的验收，不是永久稳定性或未来所有版本兼容的保证。

此次修复与代码

更新精确越狱环境指纹，并补全工作线程快照对插件自身图像的精确过滤集合； 保留身份、路径、UUID、调用位置和快照一致性校验。没有强制检查成功、屏蔽致命信号、 全局修改 dyld 图像列表或钩住系统守护进程。正式包不含临时诊断观察器。

新增 C 指纹函数、适配代码和验收记录。 完整旧 C 源码仍未找回；新增函数在已验证 1.0.57 基础上接入三个启动入口。

下载正式 1.0.58 DEB · 1.0.57 回退包（未改动）。

以后更新游戏

1.0.58 已用完整文件指纹取代三个版本号比较：已知 magicx 防护文件、systemhook 和生成的 dyld 完全不变时，不再仅因 CoC 版本号变化拒绝加载。文件变了、读取失败或环境不匹配则拒绝启用， 不猜偏移、不强制成功。其他原有身份和一致性校验保留。独立实机测试已确认：已知文件通过， 同大小但改了一个字节的副本被拒绝；真实游戏文件未修改。

尚未测试未来实际游戏版本；其他游戏代码变化仍可能引入不同问题，不能保证所有更新都无需适配。

旧版 1.0.41

原验证组合为 CoC 18.600.7 / Dopamine 3.0.10，以及 iPad14,6 / iPadOS 16.1 (20B82) 或 iPad7,2 / iPadOS 17.7.11 (21H461)。新版 1.0.57 的结果不能视为旧 iOS 17 组合的重新验收。

English

1.0.58 is regression-tested with CoC 18.647.2, iPad14,6, iPadOS 16.1 (20B82), Dopamine 3.0.11. It refreshes exact environment fingerprints and corrects qualified own-image worker snapshot filtering. No forced success, signal suppression, global dyld-list edits or system-daemon hooks are added.

Close CoC, install, reopen. Allow ClashTraceDiagnostic in a custom Choicy allowlist. No reboot/respring scripts are included. Village entry and relaunch were visually verified; the same process was observed alive at 199 seconds after returning to Virtual Mac, not tested indefinitely.

The new original C runtime gate checks full known protection/jailbreak file fingerprints instead of the app-version number at three call sites. Changed or unreadable files are refused. Known files passed a standalone device check; a same-size one-byte-altered copy was refused. Real game files were not modified.

No future real game version was tested. Other game changes can still break compatibility. The full legacy C implementation remains unavailable. The unmodified 1.0.57 rollback package and legacy 1.0.41 APT entry stay available.
