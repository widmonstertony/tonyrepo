Clash Stability iOS 17 · 1.0.0

Clash of Clans 18.600.7 的 Dopamine 兼容插件，包含后台快照刷新和回滚。

已验证组合

iPad7,2（A10X）、iPadOS 17.7.11 / 21H461、Dopamine 3.0.10，以及设备原有的 Procursus OpenSSH 9.7p1。其他硬件、系统或游戏版本尚未验证。原 iPadOS 16 插件请继续使用 Clash Stability 1.0.40。

安装前退出游戏，安装后重新打开。如果 Choicy 使用自定义允许列表，请允许 ClashTraceDiagnostic。此包与 iPadOS 16 包互斥。无需重启 SpringBoard；卸载后重新启动游戏即可移除注入。

运行库完全由 C 源码独立编译。按准确设备身份处理系统页面和当前私有快照，保留原始检查；SSH 服务和配置保持不变。源码保存在 private 仓库。

English

Verified only on iPad7,2, iPadOS 17.7.11 (21H461), CoC 18.600.7, Dopamine 3.0.10 and the installed Procursus OpenSSH 9.7p1. The runtime is compiled entirely from C with constrained snapshot refresh and rollback.

Close the game before installation, then reopen it. Allow ClashTraceDiagnostic in a custom Choicy allowlist. This package conflicts with the iPadOS 16 edition. Uninstall and restart the game to remove the tweak. No respring or SSH configuration changes are required.
