Tony Reverse Volume Keys 1.0.1

独立可选插件，只适配已核验的 iPad7,2 / iPadOS 17.7.11。默认横屏对调实体音量加减，竖屏不变；设置中可以关闭反转或「仅横屏」。不要安装到另一台 iPad 来代替共用网速包。

读取真正外层全屏窗口的横竖尺寸，不采用台前调度 App 的方向。保留按下到松开的映射、原始修饰键和返回值。不改音量滑块、Siri、音频会话、游戏或已有的固定位置音量设置。没有自动重启脚本，安装后需一次 SpringBoard 重启。

2026-10-13 横屏左向按键测试：音量 0.25 → 0.1875 → 0.25，随后恢复测试前的音量。用户确认要求的实体键行为通过；竖屏未单独自动测试，另一横屏方向未单独验证。完整记录区分仪器检查与用户确认。

English

Separate optional SpringBoard-only package for the qualified iPad7,2 /17.7.11. Defaults to reversed landscape hardware volume keys and normal portrait. Uses actual outer-display window geometry; preserves matching key-down/up mapping. No audio-session replacement, game injection, slider inversion or automatic restart scripts. Landscape-left was instrumented; the user confirmed requested physical behavior. Portrait was not separately automated and the opposite landscape was not separately tested. This is not part of the universal network-speed package.
