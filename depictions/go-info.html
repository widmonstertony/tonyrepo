GO 信息显示 0.3.1 · 预览版

原版 Pokémon GO 的 rootless 运行时插件，不重打包 IPA、不修改游戏文件， 不永久重命名宝可梦。可在 Sileo 或 Zebra 单独卸载。

功能

  • 背包列表／详情直接显示 IV 百分比、攻／防／体，3★ 橙色、4★ 红色加粗； 支持闪光和 XXS／XXL 提示，关闭开关后恢复原显示。
  • 游戏内 Discord 面板；自行登录、选择频道或在设置中填写频道链接。 不包含账号、密码、token 或私人频道配置。
  • 解析地图链接、手动坐标，确认后才启用仅影响本游戏的模拟定位。 路线支持速度、循环、暂停、摇杆、GPX 导入和保存，无需另装定位 App。

兼容性与已知限制

要求 iOS/iPadOS 15+ rootless 越狱、ElleKit 1.2+、PreferenceLoader 2.2.8+。 只适配 Pokémon GO 0.431.1，UnityFramework UUID 必须为 293d1588-b821-3070-90bf-908a63e12a7c。不匹配时拒绝读取游戏模型。

背包／详情 IV 已在 iPad14,6 / iPadOS 16.1 验证。 0.3.1 修正最低依赖声明，避免要求不必要的 PreferenceLoader 升级； 游戏内定位实机验收仍待完成，本机测试不等于游戏服务器已接受模拟位置。

此包不是越狱隐藏或游戏启动兼容补丁。 另一台 iPhone X / iOS 16.7.16 的游戏在本插件未安装时已经启动闪退， 更新到 0.431.1 后仍然闪退，问题尚未解决；不能宣称此设备可用。 注入与违规定位可能导致账号处罚，不能保证安全。

捕捉前 IV 尚未验证。路线仅在游戏前台执行；锁屏或切换 App 后暂停， 不做自动抓捕，不保证后台行走。游戏重开后模拟定位关闭。

安装与开关

  1. 退出游戏，在包管理器安装本插件。
  2. 进入「设置 → GO 信息显示」，按需开启「启用信息显示」及各功能。 总 IV 开关默认关闭；模拟定位默认关闭，需要另行确认。
  3. 重新打开游戏加载插件。如 Choicy 使用自定义允许列表，允许 GOInfo。 安装不要求自动重启 SpringBoard；如设置入口未刷新，可关闭并重开「设置」。
  4. 当前预览版每次设备重启后，须先打开一次「设置 → GO 信息显示」发布开关配置。

游戏内「100iv · 定位关」进入 Discord／定位面板； 首次登录由你手动完成，不导出 Discord 会话。关闭定位恢复系统定位。

卸载与隐私

先关闭显示／定位开关，在 Sileo 或 Zebra 卸载「GO 信息显示」，再重开游戏。 已加载的 dylib 不能从运行中的游戏热卸载。不会卸载原游戏。

安装包只包含原创插件与设置界面，不含原版游戏二进制、元数据、截图、账号容器或凭据。 本插件使用 MIT 许可证，许可证随安装包附带。

English summary

GO Info 0.3.1 is a rootless runtime preview for the original Pokémon GO app. Reversible bag/detail IV labels, 3★/4★ emphasis, in-game Discord, confirmed per-app positioning, routes, speed controls, joystick and GPX import. No IPA repackaging.

Requires iOS 15+, ElleKit 1.2+, PreferenceLoader 2.2.8+, and Pokémon GO 0.431.1 with the exact UnityFramework UUID above. Bag/detail IV was verified on iPadOS 16.1; in-game positioning validation is pending. The iPhone X startup crash remains unresolved. This is not a jailbreak-hiding or startup-crash fix. Injection/spoofing can risk your account.

Configure Settings → GO 信息显示; reopen the game after installation. Allow GOInfo in a Choicy custom allowlist. Visit the settings panel once after each device reboot. Routes pause when the app resigns active. Uninstall the package and reopen the game to remove it.
